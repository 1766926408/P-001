# P-001 邀测招募 - 快速启动指南（30分钟上线）

## ⚡ 30分钟快速启动路径

### 步骤1️⃣：准备Google Sheets（5分钟）

1. 打开 [Google Sheets](https://sheets.google.com)
2. **创建新电子表格**，命名为 `user-recruitment-base`
3. **创建4个Sheet标签页**：
   - `users-base` 
   - `feedback-log`
   - `invitation-tracking`
   - `stats-dashboard`

**Sheet 1 - users-base 标题行**：
```
A: 用户ID
B: 昵称
C: 来源渠道
D: 邀请链接
E: 加入时间
F: 群聊状态
G: 反馈内容
H: 邀请数量
I: 激励积分
J: 激励发放
```

**Sheet 2 - feedback-log 标题行**：
```
A: 来源
B: 用户
C: 反馈内容
D: 反馈时间
E: 处理状态
```

**Sheet 3 - invitation-tracking 标题行**：
```
A: 邀请者ID
B: 被邀者ID
C: 邀请链接
D: 是否转化
E: 转化时间
F: 激励状态
```

4. **获取Sheet ID**：复制URL中的ID
   ```
   https://docs.google.com/spreadsheets/d/{SHEET_ID}/edit
                                            ↑ 这个
   ```

---

### 步骤2️⃣：获取Google API权限（5分钟）

1. 打开 [Google Cloud Console](https://console.cloud.google.com)
2. 创建新项目 → 命名 `auto-recruitment`
3. **启用API**：搜索并启用
   - `Google Sheets API`
   - `Google Drive API`

4. **创建服务账号**：
   - 左侧 → Credentials（凭据）
   - Create Credentials → Service Account
   - 填写：
     ```
     Service account name: auto-recruitment-bot
     Service account ID: (自动)
     ```
   - Create and Continue
   - Grant roles: `Editor`

5. **创建JSON密钥**：
   - 点击创建的Service Account
   - Keys标签 → Add Key → Create new key
   - 选择JSON格式 → 下载

6. **共享权限**：
   - 打开下载的JSON文件，找到 `client_email`
   - 回到Google Sheet → 右上角Share
   - 粘贴client_email → 给予编辑权限

**保存JSON文件**到项目根目录，命名为 `google-credentials.json`

### 步骤4️⃣：部署核心脚本到云端（10分钟）

#### 方案A：使用GitHub Actions（推荐）

1. 创建 `.github/workflows/auto-recruitment.yml`：

```yaml
name: Auto Recruitment Bot

on:
  schedule:
    - cron: '0 6 * * *'  # 每天早6点
    - cron: '0 9 * * *'  # 每天早9点
    - cron: '0 17 * * 5' # 周五下午5点
  workflow_dispatch:

jobs:
  recruitment:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.9'
      
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      
      - name: Run recruitment bot
        env:
          GOOGLE_SHEET_ID: ${{ secrets.GOOGLE_SHEET_ID }}
          WECHAT_CORP_ID: ${{ secrets.WECHAT_CORP_ID }}
          WECHAT_AGENT_ID: ${{ secrets.WECHAT_AGENT_ID }}
          WECHAT_SECRET: ${{ secrets.WECHAT_SECRET }}
        run: |
          python main.py
```

2. 在GitHub项目的Settings → Secrets，添加：
   - `GOOGLE_SHEET_ID`
   - `WECHAT_CORP_ID`
   - `WECHAT_AGENT_ID`
   - `WECHAT_SECRET`

#### 方案B：本地运行 + PM2自动重启

```bash
# 全局安装PM2
npm install -g pm2

# 启动脚本
pm2 start main.py --name "recruitment-bot" --interpreter python3

# 设置开机自启
pm2 startup
pm2 save

# 查看日志
pm2 logs recruitment-bot
```

## ⚠️ 常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|--------|
| Google Sheet无法连接 | 权限未授予 | 重新Share Service Account Email |
| 微信机器人不回复 | Token过期 | 重新登录获取token |
| 数据未同步到Sheet | API限流 | 检查配额，添加延迟 |
| GitHub Actions超时 | 脚本运行过长 | 优化查询，使用缓存 |
