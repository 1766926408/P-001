## 🚀 方案 A: 个人企业微信（推荐，立即可用）

### ✅ 这个方案能做什么

- ✓ **发送激励通知** - 定时向用户发送积分通知
- ✓ **群发反馈总结** - 定期发送反馈汇总
- ✓ **周报推送** - 自动发送周报
- ✗ 不能接收自动回复（需要企业认证）

### 🔧 快速设置（5分钟）

#### 1️⃣ 获取企业微信基本信息

访问 https://work.weixin.qq.com/

1. 进入 **管理后台** → **我的企业**
2. 复制以下信息：
   ```
   企业ID (CorpID): wwd3c...（复制保存）
   ```

3. 进入 **应用管理** → **创建应用**
   - 应用名称：`邀测招募机器人`
   - 应用类型：`自建应用`
   - 点击 **创建**

4. 在应用详情页，复制：
   ```
   应用ID (AgentID): 1000002
   应用密钥 (Secret): xxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

#### 2️⃣ 更新 .env 文件

```env
# 企业微信配置
WECHAT_CORP_ID=wwd3c123456789abcdef1234567890ab
WECHAT_AGENT_ID=1000002
WECHAT_SECRET=abcdefghijklmnopqrstuvwxyz1234567890abcd
WECHAT_ENABLED=true
```

#### 3️⃣ 创建微信机器人模块

创建文件：`modules/wechat_bot.py`

```python
# -*- coding: utf-8 -*-
"""
企业微信机器人 - 仅发送消息（不需要企业认证）
"""

import requests
import logging
import json
from datetime import datetime
import os

logger = logging.getLogger(__name__)


class WeChatBot:
    """企业微信机器人"""

    def __init__(self):
        """初始化"""
        self.corp_id = os.getenv('WECHAT_CORP_ID')
        self.agent_id = os.getenv('WECHAT_AGENT_ID')
        self.secret = os.getenv('WECHAT_SECRET')
        self.token = None
        self._refresh_token()

    def _refresh_token(self):
        """获取或刷新access_token"""
        try:
            url = f"https://qyapi.weixin.qq.com/cgi-bin/gettoken"
            params = {
                'corpid': self.corp_id,
                'corpsecret': self.secret
            }

            response = requests.get(url, params=params, timeout=10)
            data = response.json()

            if data.get('errcode') == 0:
                self.token = data.get('access_token')
                logger.info("✅ 企业微信Token获取成功")
                return True
            else:
                logger.error(f"❌ Token获取失败: {data.get('errmsg')}")
                return False

        except Exception as e:
            logger.error(f"❌ Token刷新失败: {e}")
            return False

    def send_message(self, user_id: str, message: str) -> bool:
        """
        发送消息给用户
        
        Args:
            user_id: 用户ID或手机号
            message: 消息内容
        """
        try:
            if not self.token:
                self._refresh_token()

            url = f"https://qyapi.weixin.qq.com/cgi-bin/message/send"

            payload = {
                'touser': user_id,
                'agentid': self.agent_id,
                'msgtype': 'text',
                'text': {
                    'content': message
                },
                'safe': 0
            }

            params = {'access_token': self.token}
            response = requests.post(url, json=payload, params=params, timeout=10)
            data = response.json()

            if data.get('errcode') == 0:
                logger.info(f"✅ 消息已发送给 {user_id}")
                return True
            else:
                logger.error(f"❌ 消息发送失败: {data.get('errmsg')}")
                return False

        except Exception as e:
            logger.error(f"❌ 发送消息失败: {e}")
            return False

    def send_to_group(self, party_id: str, message: str) -> bool:
        """
        发送消息到部门
        
        Args:
            party_id: 部门ID
            message: 消息内容
        """
        try:
            if not self.token:
                self._refresh_token()

            url = f"https://qyapi.weixin.qq.com/cgi-bin/message/send"

            payload = {
                'toparty': party_id,
                'agentid': self.agent_id,
                'msgtype': 'text',
                'text': {
                    'content': message
                },
                'safe': 0
            }

            params = {'access_token': self.token}
            response = requests.post(url, json=payload, params=params, timeout=10)
            data = response.json()

            if data.get('errcode') == 0:
                logger.info(f"✅ 消息已发送到部门 {party_id}")
                return True
            else:
                logger.error(f"❌ 消息发送失败: {data.get('errmsg')}")
                return False

        except Exception as e:
            logger.error(f"❌ 发送消息失败: {e}")
            return False

    def send_notification(self, user_ids: list, title: str, content: str) -> bool:
        """
        批量发送通知
        
        Args:
            user_ids: 用户ID列表
            title: 标题
            content: 内容
        """
        try:
            message = f"{title}\n\n{content}\n\n发送时间: {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}"

            success_count = 0
            for user_id in user_ids:
                if self.send_message(user_id, message):
                    success_count += 1

            logger.info(f"✅ 已发送 {success_count}/{len(user_ids)} 条通知")
            return success_count > 0

        except Exception as e:
            logger.error(f"❌ 批量发送失败: {e}")
            return False


# 测试函数
if __name__ == '__main__':
    logging.basicConfig(level=logging.INFO)

    bot = WeChatBot()
    print("✅ 企业微信机器人初始化成功")

    # 测试发送消息
    # bot.send_message('用户ID', '测试消息')
```

### 代码示例

```python
# modules/wechat_web_bot.py
import itchat
from itchat.content import TEXT

@itchat.msg_register(TEXT, isFriendChat=True)
def reply_friend(msg):
    """自动回复朋友消息"""
    if '邀请' in msg['Text']:
        itchat.send("欢迎加入邀测群！", msg['FromUserName'])

# 启动

itchat.run()
```

**优点**：不需要认证，立即可用

### 快速设置

1. 创建钉钉群
2. 添加机器人
3. 获取Webhook URL

```env

```

### 代码

```python
import requests

def send_dingtalk(title, content):
    webhook = os.getenv('DINGTALK_WEBHOOK')
    
    data = {
        'msgtype': 'markdown',
        'markdown': {
            'title': title,
            'text': content
        }
    }
    
    requests.post(webhook, json=data)
```

**优点**：最简单，无需认证
**缺点**：需要用钉钉而不是微信

## ❓ 常见问题

### Q: 个人企业微信能收到消息吗？
**A**: ✅ 能。只要你在企业微信客户端里，机器人发的消息你都能收到。

### Q: 为什么说"需要认证"？
**A**: 企业认证主要是为了：
- 接收用户主动发来的消息（回调）
- 使用高级功能（OAuth、第三方登录等）
- 但**发送消息**（我们需要的）不需要企业认证

### Q: 消息能发给群吗？
**A**: ✅ 能。需要：
1. 创建部门
2. 添加用户到部门
3. 用部门ID发送消息

### Q: 怎么知道应用ID和Secret？
**A**: 在企业微信后台：
```
管理后台 → 应用管理 → 你的应用 → 应用详情
```

### Q: 测试时发不出消息？
**A**: 检查：
1. CorpID、AgentID、Secret 是否复制正确
2. 用户是否在企业中（需要邀请用户）
3. 应用是否有权限

## 📝 最小化示例

```python
# 最简单的企业微信发送

import os
import requests

corp_id = os.getenv('WECHAT_CORP_ID')
secret = os.getenv('WECHAT_SECRET')

# 获取token
r = requests.get(
    f'https://qyapi.weixin.qq.com/cgi-bin/gettoken',
    params={'corpid': corp_id, 'corpsecret': secret}
)
token = r.json()['access_token']

# 发送消息
requests.post(
    f'https://qyapi.weixin.qq.com/cgi-bin/message/send?access_token={token}',
    json={
        'touser': '用户ID',
        'agentid': 1000002,
        'msgtype': 'text',
        'text': {'content': '🎉 你获得了10积分！'}
    }
)

print("✅ 消息已发送")
```
