## 🌟 方案 A: 腾讯表格（推荐首选）

> 最接近Google Sheets，国内访问快速，支持API自动化

### ✅ 优点

- ✓ 完全免费
- ✓ 国内访问快速（无需科学上网）
- ✓ 功能和Google Sheets几乎一样
- ✓ 支持链接分享、权限管理
- ✓ 支持公式和自动计算
- ✓ 可导入导出CSV/Excel

### ❌ 缺点

- API文档不够详细（但有替代方案）
- 无法像Google Sheets API那样直接调用

## 💻 方案 B: SQLite 本地数据库（推荐备选）

> 最稳定的方案，完全本地，无需网络依赖

### ✅ 优点

- ✓ 完全本地化，不依赖任何网络服务
- ✓ 速度快，零成本
- ✓ 数据完全自己管理
- ✓ Python内置支持，无需额外依赖
- ✓ 可导出为Excel查看

### ❌ 缺点

- 不能像表格那样在线编辑和分享
- 需要用脚本生成Excel报表来查看

### 🚀 快速迁移步骤

#### 2️⃣ 创建数据库模式

```python
# modules/sqlite_manager.py
import sqlite3
from datetime import datetime
import uuid

class SQLiteManager:
    """SQLite 数据库管理器"""
    
    def __init__(self, db_path='recruitment.db'):
        self.db_path = db_path
        self.conn = sqlite3.connect(db_path)
        self.cursor = self.conn.cursor()
        self._init_tables()
    
    def _init_tables(self):
        """初始化数据库表"""
        
        # 用户表
        self.cursor.execute('''
            CREATE TABLE IF NOT EXISTS users (
                user_id TEXT PRIMARY KEY,
                nickname TEXT,
                source TEXT,
                invite_link TEXT,
                join_time TEXT,
                group_status TEXT,
                feedback TEXT,
                invite_count INTEGER DEFAULT 0,
                reward_points INTEGER DEFAULT 0,
                reward_status TEXT DEFAULT '待发放',
                created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
            )
        ''')
        
        # 反馈表
        self.cursor.execute('''
            CREATE TABLE IF NOT EXISTS feedback (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                source TEXT,
                user TEXT,
                content TEXT,
                feedback_time TEXT,
                status TEXT DEFAULT '未读',
                created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
            )
        ''')
        
        # 邀请追踪表
        self.cursor.execute('''
            CREATE TABLE IF NOT EXISTS invitations (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                inviter_id TEXT,
                invitee_id TEXT,
                invite_link TEXT,
                is_converted TEXT DEFAULT '待转化',
                convert_time TEXT,
                reward_status TEXT DEFAULT '待处理',
                created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
            )
        ''')
        
        self.conn.commit()
    
    def add_user(self, nickname: str, source: str) -> str:
        """添加新用户"""
        user_id = str(uuid.uuid4())[:8]
        
        self.cursor.execute('''
            INSERT INTO users 
            (user_id, nickname, source, join_time, group_status)
            VALUES (?, ?, ?, ?, ?)
        ''', (user_id, nickname, source, datetime.now().isoformat(), '已加入'))
        
        self.conn.commit()
        return user_id
    
    def get_all_users(self):
        """获取所有用户"""
        self.cursor.execute('SELECT * FROM users')
        columns = [desc[0] for desc in self.cursor.description]
        return [dict(zip(columns, row)) for row in self.cursor.fetchall()]
    
    def get_stats(self):
        """获取统计数据"""
        self.cursor.execute('SELECT COUNT(*) as total FROM users')
        total = self.cursor.fetchone()[0]
        
        self.cursor.execute("SELECT COUNT(*) as count FROM users WHERE source='wechat'")
        wechat = self.cursor.fetchone()[0]
        
        self.cursor.execute("SELECT COUNT(*) as count FROM feedback")
        feedback_count = self.cursor.fetchone()[0]
        
        return {
            'total_users': total,
            'wechat_users': wechat,
            'qq_users': total - wechat,
            'feedback_count': feedback_count,
            'timestamp': datetime.now().isoformat()
        }
    
    def export_to_excel(self, output_file='report.xlsx'):
        """导出数据到Excel"""
        import pandas as pd
        
        df_users = pd.read_sql_query('SELECT * FROM users', self.conn)
        df_feedback = pd.read_sql_query('SELECT * FROM feedback', self.conn)
        df_invites = pd.read_sql_query('SELECT * FROM invitations', self.conn)
        
        with pd.ExcelWriter(output_file) as writer:
            df_users.to_excel(writer, sheet_name='users')
            df_feedback.to_excel(writer, sheet_name='feedback')
            df_invites.to_excel(writer, sheet_name='invites')
        
        print(f"✅ 数据已导出到 {output_file}")
```

## 📝 方案 C: JSON 文件（快速原型）

> 最简单的方案，适合快速测试原型

### 代码示例

```python
# modules/json_manager.py
import json
from datetime import datetime
import uuid

class JSONManager:
    """JSON文件管理器"""
    
    def __init__(self, data_dir='data'):
        self.data_dir = data_dir
        self.users_file = f'{data_dir}/users.json'
        self.feedback_file = f'{data_dir}/feedback.json'
        self._init_files()
    
    def _init_files(self):
        """初始化JSON文件"""
        import os
        os.makedirs(self.data_dir, exist_ok=True)
        
        if not os.path.exists(self.users_file):
            with open(self.users_file, 'w') as f:
                json.dump([], f)
        
        if not os.path.exists(self.feedback_file):
            with open(self.feedback_file, 'w') as f:
                json.dump([], f)
    
    def add_user(self, nickname: str, source: str) -> str:
        """添加用户"""
        with open(self.users_file, 'r') as f:
            users = json.load(f)
        
        user_id = str(uuid.uuid4())[:8]
        users.append({
            'user_id': user_id,
            'nickname': nickname,
            'source': source,
            'join_time': datetime.now().isoformat(),
            'group_status': '已加入'
        })
        
        with open(self.users_file, 'w') as f:
            json.dump(users, f, ensure_ascii=False, indent=2)
        
        return user_id
    
    def get_all_users(self):
        """获取所有用户"""
        with open(self.users_file, 'r') as f:
            return json.load(f)
    
    def get_stats(self):
        """获取统计"""
        users = self.get_all_users()
        return {
            'total_users': len(users),
            'wechat_users': len([u for u in users if u['source'] == 'wechat']),
            'timestamp': datetime.now().isoformat()
        }
```

## 🎯 选择建议

### 使用 **腾讯表格** 如果你：
- ✅ 需要在线编辑和团队协作
- ✅ 想要类似Google Sheets的体验
- ✅ 需要分享链接给其他人查看
- ✅ 不想折腾太多技术

### 使用 **SQLite** 如果你：
- ✅ 想要最稳定的本地方案
- ✅ 不需要实时在线访问
- ✅ 可以接受定期导出Excel查看
- ✅ 数据完全自己掌控

### 使用 **JSON** 如果你：
- ✅ 只是快速测试原型
- ✅ 数据量很小（<1000条）
- ✅ 需要快速启动
