## 🔄 定时任务详解

### 每天 06:00 - 激励积分计算

```python
# 自动执行逻辑
for each_user:
    积分 = 0
    if 已加入群:     积分 += 5
    if 已反馈:       积分 += 10
    if 邀请数量>0:   积分 += 邀请数量 * 15
    更新用户积分()
```

### 每天 09:00 - 激励推送通知

```
目标用户：待发放状态且积分>0
推送消息：
  🎉 您已获得 {积分} 积分！
  可兑换：50积分=8折优惠券 / 100积分=免费1个月
  继续参与反馈、邀请朋友获得更多积分！
状态更新：标记为"已发放"
```

### 每周五 17:00 - 周报自动生成

```
报告内容：
├─ 概览数据（新增用户、反馈数、反馈率）
├─ 渠道分析（各渠道用户分布）
├─ 反馈分析（关键词、分类、热点问题）
├─ 用户排行（Top 5活跃用户）
└─ 建议（基于数据的优化建议）

输出格式：
├─ 保存为 JSON 报告
├─ 发送到钉钉/企业微信（可选）
└─ 在 Google Sheet 中更新
```

## ⚠️ 注意事项

### 1️⃣ 账号风险预防

微信/QQ账号可能因频繁操作被限制，解决方案：

```
✓ 准备 2-3 个备用微信/QQ号
✓ 轮流发布内容，降低单账号频率
✓ 添加随机延迟，模拟正常用户行为
✓ 监控日志，及时发现异常
```

### 2️⃣ 数据备份

```
✓ 每天凌晨 02:00 自动备份到 backups/ 目录
✓ 周建议手动导出一次关键数据
✓ Google Sheet 本身有版本历史，可恢复
```

### 3️⃣ 定时任务故障

```
症状：任务未执行
解决：
  1. 检查 logs/recruitment.log
  2. 运行 python scripts/test_connection.py
  3. 查看 GitHub Actions 执行历史（如使用GH运行）
```
