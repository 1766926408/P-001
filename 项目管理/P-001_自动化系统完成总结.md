## 🔧 系统配置速查表

### 修改执行时间

文件：`.github/workflows/auto_tasks.yml`

```yaml
on:
  schedule:
    - cron: '0 22 * * *'  # 改这里改时间（UTC）
```

时区转换：
- 北京时间 (CST) = UTC + 8
- 例如：09:00 CST = 01:00 UTC = `cron: '0 1 * * *'`

### 禁用某个任务

文件：`scripts/run_auto_tasks.py`

```python
# 找到对应任务，注释掉即可
# elif hour == 9:
#     results['distribute_rewards'] = distribute_rewards()
```

### 添加新任务

1. 在 `scripts/run_auto_tasks.py` 中添加函数
2. 在 `run_scheduled_tasks()` 中添加条件
3. 在 `.github/workflows/auto_tasks.yml` 中添加 cron

## ❓ 常见问题

### Q: 如果域名迟迟备案不通过怎么办？
A: 系统会持续运行，继续积累用户和反馈。备案完成后，直接启用数据迁移脚本即可上线。

### Q: 能否随时停止自动化？
A: 可以。禁用工作流：GitHub Actions 页面 → 工作流 → 右上角菜单 → Disable workflow

### Q: 数据库会越来越大吗？
A: 会，但增长缓慢。100个用户的数据库约 1MB。如需维护，可定期归档历史数据。

### Q: 自动化失败了怎么办？
A: GitHub Actions 会自动重试。如果多次失败，检查日志找到原因。大多数问题都能通过更新 `requirements.txt` 解决。

### Q: 能否在手机上看到执行状态？
A: 可以。GitHub 提供手机 App，可以查看 Actions 执行日志。
