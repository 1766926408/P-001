# P-001 邀测招募 - 大众化方案对比

> 放弃企业微信，用大众都能接受的方案

---

## 🎯 核心问题

企业微信的问题：
- ❌ 需要用户额外安装应用
- ❌ 许多人不知道企业微信是什么
- ❌ 需要邀请用户加入企业

**更好的方案是什么？** 用大众都已经在用的工具！

---

## 📊 4大大众化方案对比

| 方案 | 易用度 | 大众度 | 功能 | 推荐指数 |
|------|--------|--------|------|---------|
| **微信公众号** ⭐⭐⭐⭐⭐ | 最简单 | 最高 | 自动回复、群发、菜单 | **强烈推荐** |
| **钉钉群机器人** ⭐⭐⭐⭐ | 简单 | 高（企业用户） | 自动回复、群发 | **推荐** |
| **QQ群或飞书群** ⭐⭐⭐⭐ | 简单 | 高 | 群公告、群机器人 | **备选** |
| **在线表单 + 链接** ⭐⭐⭐ | 很简单 | 极高 | 数据收集、自动同步 | **辅助方案** |

## 🥇 方案 #1: 微信公众号（最推荐）

### ✅ 为什么最好

- ✓ **大众都用** - 每个用微信的人都知道公众号
- ✓ **无需安装** - 直接关注即可，无额外负担
- ✓ **功能完整** - 自动回复、群发、菜单、投票
- ✓ **易于分享** - 可生成二维码，分享给任何人
- ✓ **无需认证** - 订阅号就行，不用企业认证
- ✓ **免费** - 完全免费

### ❌ 缺点

- 不能实时接收用户的具体消息（只能读通知）
- 需要5-10分钟设置自动回复

### 🚀 快速设置（10分钟）

#### 1️⃣ 注册微信公众号

访问 https://mp.weixin.qq.com/

```
账号类型：订阅号（个人可用）
公众号名称：邀测招募 / 或你的产品名
```

#### 2️⃣ 设置自动回复

```
左侧菜单 → 自动回复 → 启用

【关键词回复】
关键词：邀请
回复：欢迎加入邀测！点击链接填写信息 [链接]

关键词：反馈
回复：感谢反馈！我们已记录，你获得了10积分 🎁

关键词：积分
回复：你的当前积分：{积分}，继续参与获得更多积分！
```

#### 3️⃣ 群发消息功能

```
左侧菜单 → 群发消息

每天可群发：
  • 早9点 - 激励通知："你获得了X积分"
  • 周五5点 - 周报通知："本周邀测进展..."
```

#### 4️⃣ 生成二维码

```
设置 → 在线生成二维码

分享给用户：
  • 论坛回帖时附上二维码
  • 知乎评论中放二维码
  • 邀请链接中包含二维码
```

### 💻 代码集成

```python
# modules/wechat_official.py
"""
微信公众号群发接口
"""

import requests
import logging

logger = logging.getLogger(__name__)

class WeChatOfficialAccount:
    """微信公众号"""
    
    def __init__(self, app_id, app_secret):
        self.app_id = app_id
        self.app_secret = app_secret
        self.token = None
        self._refresh_token()
    
    def _refresh_token(self):
        """获取access_token"""
        url = f"https://api.weixin.qq.com/cgi-bin/token"
        params = {
            'grant_type': 'client_credential',
            'appid': self.app_id,
            'secret': self.app_secret
        }
        
        response = requests.get(url, params=params)
        self.token = response.json()['access_token']
    
    def send_broadcast(self, message: str, filter_type: str = 'all'):
        """
        群发消息给所有粉丝
        
        Args:
            message: 消息内容
            filter_type: 'all'=所有粉丝, 'follower'=已关注
        """
        url = f"https://api.weixin.qq.com/cgi-bin/message/mass/send"
        
        payload = {
            'filter': {
                'is_to_all': filter_type == 'all'
            },
            'mpnews': {
                'media_id': 'xxx'  # 需要先上传素材
            },
            'msgtype': 'mpnews'
        }
        
        params = {'access_token': self.token}
        requests.post(url, json=payload, params=params)
        
        logger.info("✅ 群发消息已发送")
```

## 🥈 方案 #2: 钉钉群机器人（企业首选）

### 适合场景

- 你的邀测用户主要是企业员工
- 团队内部在用钉钉

### 快速设置

```
1. 创建钉钉群
2. 群设置 → 机器人 → 添加机器人
3. 选择"自定义"机器人
4. 获取 Webhook URL

环境变量：
DINGTALK_WEBHOOK=https://oapi.dingtalk.com/robot/send?access_token=xxx
```

### 代码示例

```python
import requests
import os

def send_dingtalk(title: str, content: str):
    webhook = os.getenv('DINGTALK_WEBHOOK')
    
    data = {
        'msgtype': 'markdown',
        'markdown': {
            'title': title,
            'text': f"## {title}\n\n{content}"
        }
    }
    
    requests.post(webhook, json=data)

# 使用示例
send_dingtalk(
    '🎉 恭喜！',
    '你获得了10积分！\n\n继续参与反馈获得更多积分'
)
```

## 🥉 方案 #3: QQ群 + 官方公告

### 适合场景

- 用户主要是QQ用户
- 想要最直接的互动

### 优点

- QQ是国民应用
- 群公告自动推送给所有成员
- 支持群投票、群打卡等

### 做法

```
1. 创建QQ群
2. 群设置 → 群公告

每周发布：
  • 周一：本周目标
  • 周三：进度更新
  • 周五：周报 + 排行榜

自动化：
  • 用Python selenium模拟QQ登录（不推荐）
  • 或手动每周更新一次（更可靠）
```

## 🌟 方案 #4: 在线表单（最简单）

> 结合上面的方案使用，用来收集用户反馈

### 工具选择

| 工具 | 特点 | 推荐度 |
|------|------|--------|
| **Google Forms** | 功能强大，自动同步Google Sheet | ⭐⭐⭐⭐⭐ |
| **腾讯表单** | 国内可用，支持分享 | ⭐⭐⭐⭐⭐ |
| **问卷星** | 免费，易用 | ⭐⭐⭐⭐ |
| **JimdoForms** | 简单轻量 | ⭐⭐⭐ |

### 快速设置

```
1. 创建表单（以腾讯表单为例）
   https://docs.qq.com/form/

2. 添加字段：
   - 用户名
   - 邮箱或手机
   - 反馈内容
   - 建议

3. 生成链接：
   https://docs.qq.com/form/page/xxxx

4. 分享给用户
   - 论坛里贴链接
   - 知乎评论里贴链接
   - 微信公众号菜单里放链接
```

### 自动同步到SQLite

```python
# 定时从表单导出CSV，自动同步到SQLite

import pandas as pd
from modules.sqlite_manager import SQLiteManager

def sync_form_to_db():
    """从表单同步数据到数据库"""
    
    # 1. 从表单下载CSV（手动或API）
    df = pd.read_csv('feedback_form.csv')
    
    # 2. 同步到数据库
    db = SQLiteManager()
    
    for _, row in df.iterrows():
        db.add_feedback(
            source='form',
            user_name=row['用户名'],
            content=row['反馈内容']
        )
    
    db.close()
    print("✅ 表单数据已同步")

# 每天凌晨1点自动运行
# （在main.py中添加定时任务）
```
