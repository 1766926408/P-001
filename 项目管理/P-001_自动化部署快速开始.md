## ⏰ 自动执行时间表

GitHub Actions 将在以下时间**自动运行**（无需手动操作）：

| 时间 | 任务 | 说明 |
|------|------|------|
| **每天 06:00** | 计算激励 | 计算用户昨天的积分 |
| **每天 09:00** | 发放通知 | 推送激励消息给用户 |
| **每天 10:00** | 同步数据 | 从问卷星导入新用户 |
| **每周五 17:00** | 生成周报 | 生成 Excel 报告 |

> ⚠️ 时间基于 **GitHub 服务器时间（UTC）**。如需调整到中国时间，请参考 [[P-001_GitHub_Actions_部署指南#⏰-执行时间表说明|部署指南中的时区说明]]

## 🔍 故障排查快速指南

### 问题：工作流没有出现

**原因**：文件还没有推送到 GitHub  
**解决**：重新运行 Step 4（`git push`）

### 问题：工作流显示为"disabled"

**原因**：GitHub 禁用了工作流  
**解决**：
1. 打开 GitHub 仓库页面
2. 点击 "Actions" 标签
3. 点击 "MotorMind Auto Tasks"
4. 点击右上角的 "..." 菜单
5. 选择 "Enable workflow"

### 问题：手动运行失败，显示 ModuleNotFoundError

**原因**：缺少 Python 依赖  
**解决**：
```bash
# 更新依赖
pip install pandas openpyxl

# 本地测试
python scripts/sync_form_to_db.py

# 如果本地成功，重新推送
git push origin main
```

### 问题：数据没有被同步

**原因**：CSV 文件不存在或路径错误  
**解决**：
1. 确保 `wjx_export.csv` 在项目根目录
2. CSV 文件是从问卷星后台导出的
3. 检查 GitHub Actions 日志中的具体错误信息
