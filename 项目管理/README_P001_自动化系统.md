### 自动化工作流

```
GitHub Actions 24/7
    │
    ├─[06:00] → 计算激励积分
    │           ↓
    │           modules/rewards.py → calculate_daily_rewards()
    │
    ├─[09:00] → 发放激励通知
    │           ↓
    │           modules/rewards.py → distribute_rewards()
    │
    ├─[10:00] → 同步表单数据
    │           ↓
    │           scripts/sync_form_to_db.py
    │
    └─[周五 17:00] → 生成周报
                    ↓
                    scripts/export_weekly_report.py
                    
     所有操作 → SQLite 数据库 → Git 自动备份
```

## 📋 核心问题解答

### Q: 系统什么时候开始工作？
**A**: 推送到 GitHub 后，GitHub Actions 会在设定的时间点自动执行。首次可能需要 10-15 分钟启用。

### Q: 需要本地机器一直开着吗？
**A**: 不需要！GitHub 在云端执行，24/7 运行。

### Q: 成本是多少？
**A**: 完全免费！GitHub 提供每月 2000 分钟的免费额度，本系统月耗用 < 1 小时。

### Q: 数据安全吗？
**A**: 完全安全。数据存储在 SQLite（你的本地机器或 GitHub 仓库），通过 Git 版本控制自动备份。

### Q: 能否随时修改或停止？
**A**: 可以。代码全部开源，可随时修改。禁用工作流只需在 GitHub 页面点击按钮。

### Q: 支持什么通知方式？
**A**: 已支持企业微信。可选择配置微信公众号、钉钉等。
