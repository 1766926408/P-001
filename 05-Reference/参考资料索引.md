# 参考资料索引

## BNO080 协议要点

- I2C 每次事务从 byte0 重置，**必须单次读取完整帧**
- ARVR_RV（9轴）：Yaw 有磁力计锚定，绝对方向
- ARVR_GRV（6轴）：Yaw 相对，长时漂移
- 上电后约 800ms 才响应 I2C（`softReset` 后需等待）

## Arduino 固件版本规范

```
# ver: {IMU型号} {控制板} v{版本号}
# 例: # ver: BNO080/BNO085 ESP32-S3 v1.2
```

- 每次改动必须同步更新 `FW_VER` 常量 + 文件头 changelog
- 备份命名：含 FW_VER + 日期

## ESP32 双核 RTOS 规范

- 多任务共享外设：用互斥量或 `vTaskSuspend/Resume` 保护
- I2C 总线分配：Bus A → Core1，Bus B → Core0
- 任务通知：`xTaskNotifyGive` / `ulTaskNotifyTake`
