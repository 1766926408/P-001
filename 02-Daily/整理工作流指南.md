# 随手记整理工作流

## 🎯 核心流程

```
周一～周四：自由捕捉
    ↓
每周五下班前：触发整理
    ↓
Claude 自动整理 & 润色
    ↓
生成"本周思维总结"
    ↓
周末 or 周一查看 & 反思
```

---

## 💬 周五整理话术

### **标准整理指令**

每周五，你只需复制粘贴以下内容，替换日期即可：

```
请帮我整理 2026-04-14 到 2026-04-18 的随手记。

操作步骤：
1. 读取 02-Daily/ 目录下这一周的所有笔记
2. 提取其中的核心想法、遇到的问题、学到的技巧
3. 按以下分类整理：
   - 技术洞察（与编程/架构相关）
   - 产品思考（与功能设计相关）
   - 学到的技巧（有实用价值的方法/工具）
   - 未解决的问题（需要继续跟进的事项）
4. 润色语言，确保表述清晰、逻辑连贯
5. 为每条想法添加简短的上下文说明
6. 生成一份 Markdown 格式的总结，保存到 02-Daily/本周思维总结-2026-W16.md

输出格式参考：02-Daily/本周思维总结-模板.md
```

## 🔄 进阶：自动整理（可选）

如果想完全自动化，可以设置：

### 选项 1：使用 Claude API 定时调用
需要编写小脚本，在 Python 中：
```python
import anthropic
from datetime import datetime, timedelta

client = anthropic.Anthropic()

# 每周五 17:00 自动执行
week_start = datetime.now() - timedelta(days=datetime.now().weekday())
week_end = week_start + timedelta(days=4)

prompt = f"整理 {week_start} 到 {week_end} 的随手记..."
response = client.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=2000,
    messages=[{"role": "user", "content": prompt}]
)
```

### 选项 2：使用外部服务
- IFTTT + Claude API
- Make (formerly Integromat) + Claude API
- GitHub Actions + Claude API

### 选项 3：等待 Claude 官方 Schedule 功能支持
当你能登录时，直接用 `/schedule` 一句话解决。
