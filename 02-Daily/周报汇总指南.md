# 周报汇总指南（简化版）

## 📋 核心流程

```
整个周：在 02-Daily/日常随手记.md 随意记录
       ↓
每周五 17:00：复制本周内容，发给 Claude 汇总
              ↓
             Claude 整理 → 生成周报
```

---

## 💬 每周五的一句话

复制以下指令，替换日期，粘贴给 Claude：

```
请帮我汇总 2026-04-14 到 2026-04-20 的随手记。

只整理**技术洞察、学到的技巧、遇到的问题**这三部分。
格式：简洁 Markdown，生成到 02-Daily/本周汇总-W16.md

[粘贴本周内容]
```

---

## 📊 期望输出

Claude 会生成类似这样的文件：

```markdown
# W16 本周汇总 (2026-04-14 ~ 2026-04-20)

## 🧠 技术洞察
- 关键想法 1
- 关键想法 2

## 🔧 学到的技巧
- 技巧 1：简短说明
- 技巧 2：简短说明

## 🐛 遇到的问题
- 问题 1：进展中
- 问题 2：已解决
```

---

## ⏰ 节奏

| 时间 | 操作 | 耗时 | 成本 |
|-----|-----|------|------|
| 周一～周五 | 随意记录 | 随意 | 0 token |
| 周五 17:00 | 发给 Claude | 1 分钟 | ~2K token |
| **月均** |  |  | **~8K token** |

---

## 🔒 隐私

- ✅ 私人项目：记在这里，不做周报
- ✅ 公开项目：整理后做周报
- ✅ 外部不可见：只有你和 Claude 知道

---

## ✨ 就这么简单

1. **随时记录** → `02-Daily/日常随手记.md`
2. **周五整理** → 复制本周内容给 Claude
3. **获得周报** → Claude 生成汇总文件
4. **下周继续** → 周一开始新周记录

*没有繁琐的格式，没有复杂的流程，只有有价值的汇总。*
