## 日常场景速查

### 早上规划（每日 9:00）

```bash
"生成今日进度清单"              # 查看公司项目今日重点
"生成 P-001 的今日进度清单"     # 查看 MM 项目今日重点
```

```bash

"生成 Bug 统计"                 # 公司 Bug 统计
```

```bash
"生成本月进度清单"              # 公司项目月报

"生成 P-001 的本月进度清单"     # P-001 月报
"分析 MM 的 Bug 趋势"           # P-001 质量评估
```

## 常见问题

### Q: 默认查询会包含私人项目吗？
**A**: 不会。默认查询只看公司项目。私人项目需要明确提及（如"P-001"）。

### Q: 如何只看某个项目的信息？
**A**: 在工具名称后加上项目名。例如：
```
"生成 P-001 的进度清单"
"生成 MotorMind 的 Bug 统计"
```

### Q: 可以同时查询多个项目吗？
**A**: 可以分别查询。例如：
```
"生成公司项目的 Bug 统计"（所有公司项目）
"生成 P-001 的 Bug 统计"（P-001 项目）
"生成 P-002 的 Bug 统计"（P-002 项目）
```

### Q: 项目代码忘了怎么办？
**A**: 查看 [[项目命名规范]] 或 [[项目识别规则]]。
