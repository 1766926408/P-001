# 项目命名规范

> **原则**：保护隐私，降低辨识度，仅保留技术信息。

---

## 项目代码映射

| 内部名称 | 项目代码 | 说明 |
|---------|--------|------|
| MotorMind | **P-001** | 主要项目（隐晦处理） |
| IMU Tool | **P-002** | 工具项目 |
| 其他项目 | P-003, P-004... | 按需扩展 |

## 需求/功能代码

| 内容 | 代码格式 | 示例 |
|-----|--------|------|
| 具体需求 | REQ-XXX | REQ-001, REQ-002 |
| 具体功能 | FEAT-XXX | FEAT-001, FEAT-002 |
| 优化任务 | OPT-XXX | OPT-001, OPT-002 |

## 使用示例

### ❌ 不隐晦的记录
```
项目：MotorMind
应用：无人机控制系统
需求：提高 FOC 调参效率
```

### ✅ 隐晦的记录
```
项目：P-001
应用：Scenario-A
需求：REQ-001（参数优化工具）
```
