# 进度清单生成工具

> **用途**：每日/每周自动生成待办清单，帮助单人快速掌握当前进度。

---

## 使用方式

### 项目识别
- **默认**：`"生成进度清单"` → 所有公司项目
- **私人项目**：`"生成 P-001 的进度清单"` → 仅 P-001
- **公司项目**：`"生成[项目名]的进度清单"` → 指定项目

详见 [[项目识别规则]]

### 每日早上（推荐 9:00）
```
告诉我："生成今日进度清单"
或
告诉我："生成 P-001 的今日进度清单"（如果指定项目）
```

我会自动提取：
- 📌 **本周重点**：7.7 ~ 7.14 条目中 🔧 需完善的项
- 📋 **待处理**：❌ 未开始的下一个模块
- ⚠️ **风险**：有问题或阻碍的条目
- ✅ **本周完成**：已完成的条目总结

### 每周五（推荐 EOD）
```
告诉我："生成本周周报"
```

我会自动生成：
- 代码提交数
- 完成的功能条目
- Bug 修复情况
- 遇到的问题
- 下周计划

## 如何触发

**方案 A：手动触发**（推荐简单）
```
你说：生成今日/本周进度清单
我：立即生成并展示
```

**方案 B：定时自动**（推荐高效）
```
我配置 /schedule 定时任务：
  - 每天 9:00 自动生成今日清单
  - 每周五 17:00 自动生成周报
```

你可以选择方案，我来配置。
