# BUG-004 MPU6050 PID 正反馈发散

## 现象
PID 控制发散，反馈越调越偏，系统不稳定。

## 根本原因
读取 MPU6050 数据时**轴映射选错**，导致误差计算方向反向，PID 形成正反馈。

## 解决方案
修正轴映射，确认 Roll/Pitch 方向与舵机控制方向一致（同向为负反馈）。

## 调试建议
PID 上电后先手动倾斜，观察舵机响应：
- 倾斜 → 舵机反向补偿 = **正常**
- 倾斜 → 舵机同向加速 = **正反馈，检查轴映射**
