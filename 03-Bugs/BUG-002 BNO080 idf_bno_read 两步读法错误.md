# BUG-002 BNO080 idf_bno_read 两步读法错误

## 现象
`idf_bno_read()` 读取数据不正确，数据帧错位。

## 根本原因
BNO080 的 I2C 协议规定：**每次 I2C 事务都从 byte0 重置**。
原来的两步读法（先读长度，再读数据）会导致第二次事务重新从 byte0 开始，
读到的是头部而非数据。

## 解决方案
改为**单次读取 28 字节**，一个 I2C 事务完成。

```c
// 修改前：两步读法
i2c_read(addr, header_buf, 4);       // 读头4字节获取长度
i2c_read(addr, data_buf, length);    // 再读数据（错误！重置到byte0）

// 修改后：单次读法
i2c_read(addr, full_buf, 28);        // 一次读完整28字节
```
