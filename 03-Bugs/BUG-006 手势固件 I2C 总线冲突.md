# BUG-006 I2C 总线多任务冲突

## 现象
特定命令发送时，I2C 通信偶发错误或死锁。

## 根本原因
ESP32 双核架构中，两个任务同时访问同一个 I2C 总线，造成总线冲突。

## 解决方案
在命令处理前，先挂起另一个 I2C 访问任务：

```cpp
vTaskSuspend(task_peripheral);   // 挂起 Core0 外设采集任务
// ... 执行命令 ...
vTaskResume(task_peripheral);    // 恢复
```

## 注意
RTOS 中凡是多任务共享外设，必须用互斥量或任务挂起保护临界区。
